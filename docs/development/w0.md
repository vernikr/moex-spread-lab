Date: 2026-10-27

## Delivered

- Python 3.12.14 is pinned in `.python-version` and `pyproject.toml`.
- `config/run-manifest.json` pins the run, trial counter, offline mode, module manifest, fixture artifact and source-request rights status.
- `config/modules/w0.json` declares the W0 module contract and capabilities.
- `fixtures/w0/replay.json` is synthetic test data and contains no market claim.
- `src/moex_spread_lab/w0.py` provides canonical hashing, manifest/artifact validation, deterministic fixture normalization and repository secret scanning.
- `src/moex_spread_lab/cli.py` provides offline replay, manifest validation and secret-scan commands.
- `reports/w0/replay.json` records the committed deterministic replay result.

## Commands

```bash
uv run python -m unittest discover -s tests -v
uv run python -m moex_spread_lab.cli validate-manifest \
  --manifest config/run-manifest.json
uv run python -m moex_spread_lab.cli replay \
  --manifest config/run-manifest.json \
  --fixture fixtures/w0/replay.json \
  --output reports/w0/replay.json
uv run python -m moex_spread_lab.cli secret-scan --root . --tracked-only
```

The replay command does not use the network. It sorts fixture records by stable ID and records both the raw fixture hash and normalized-fixture hash.
