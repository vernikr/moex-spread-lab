## Shared evidence standard

- Current facts: use research execution date; do not reuse the pack date as today's date if run later. Historical claims need valid-from/valid-to and availability times.
- Primary issuer/regulator/exchange/broker/API documents first. Marketing summaries, forums, books and videos cannot establish account-specific permissions or charges.
- Each material claim: exact source, relevant page/section, date/version, scope, short supporting excerpt, and remaining uncertainty. No invented URLs, confirmations, measurements, access or citations.
- Separate verified current rules, historical evidence, hypotheses, recommended tests and unresolved account questions. Missing values are unknown, not zero/free/unlimited.
- No trades, credentials, paid services, production probes, live account operations or large data downloads requested. Small public read-only checks are optional if permitted; disclose whether actually run. Otherwise propose reproducible checks.
- Give decision tables, calculations and falsification criteria rather than a generic topic survey. Explicitly allow “not feasible” and “insufficient data.”
- Recommend architecture/stack only as evidence-backed alternatives for stages 5–6; do not start implementing them.

### Как заказывать и передавать точечное извлечение

1. **Сначала выбор:** для книги — автор, название, реальное издание и оглавление/указатель; для канала — проверенная официальная ссылка и список подходящих эпизодов/постов. Если нужный фрагмент уже известен, этап общего содержания пропустить.
2. **Затем конкретный запрос:** передать выбранному агенту строку Sxx, вопросы и сам материал/доступную публичную ссылку. Внешний агент не видит этот README автоматически. Полный исследовательский промпт по-прежнему содержит задачу; строки таблицы добавляются при заказе дополнительного изучения источника.
3. **Минимально достаточный фрагмент:** главы с определениями, формулами и ограничениями, а не вырванная цитата; у видео — транскрипт и нужные слайды; у Telegram — исходный пост, относящиеся к нему исправления и документы. Сначала ограниченный набор материалов по конкретному пробелу, не весь канал. Целая выгрузка оправдана только если точечный отбор невозможен и заранее определены вопрос, период и допустимый объём.
4. **Доказательная привязка без шаблона:** ответ на вопросы в любом формате с изданием/страницами либо URL/ID сообщения/видео/таймкодами, календарной датой публикации, известными датами правок и ограничениями. Таймкод видео не заменяет дату публикации; текущий экспорт поста не доказывает неизменность текста в прошлом. Если доступность во времени не установлена, не использовать как доказанный исторический признак.
5. **Границы вывода:** различать утверждение источника и собственную оценку применимости; отмечать «не раскрыто». Не заменять исходный документ презентацией, индивидуальное условие счёта — каналом, а будущий тест — обещанием доходности. Читать/передавать только законно доступные материалы; копировать полные книги в репозиторий не требуется. Анонимные сигнальные каналы не являются подтверждением результата стратегии.

The focused review records the subset accepted as architecture inputs; account-specific and execution claims remain pending. Returned reports will be checked for traceability, chronology, missing account scope, contradiction, cost double-counting and data limitations before being accepted for live or financial conclusions. Their findings can revise stage 1 and the provisional risk policy; later stage artifacts must reference the accepted evidence. Do not choose real-trading parameters from unsupported precision.
