# H3-F1 — Funding-only carry hypothesis

Date: 2026-11-03

## Status

`H3-F1` is a separate exploratory proxy hypothesis. It is not an optimization or parameter selection for H2-S1. It removes H2-S1's basis-median entry/exit condition to test whether positive CNYRUBF funding alone can compensate for the dated-leg basis path.

## Frozen specification

Position: short one `CNYRUBF` contract and long one `CRZ6` contract.

- use the previous 20 common EOD observations;
- enter on the next observation when mean received funding is positive;
- exit on the next observation when mean received funding is non-positive, when the five-day expiry buffer begins, or before the observable ten-trading-day perpetual execution window;
- hold at most one spread and do not roll `CRZ6`;
- use the same EOD settlement proxy, cost scenarios, LQDT benchmark and one-observation delay as H2-S1;
- mark any remaining position at data end as open, without inventing an assignment payment.

## Result

Run window: `2025-06-17`–`2026-10-27`; 349 common EOD observations; initial virtual capital RUB 30,000; current MOEX/VTB cost sensitivity.

| Metric | Result |
|---|---:|
| Closed proxy round trips | 1 |
| Position open at data end | 1 |
| Gross P&L | −RUB 686.24 |
| Current exchange/clearing costs | RUB 3.38 |
| Final `X` versus matched LQDT | **−RUB 7,694.91** |

The current account-risk screen is embedded in the output and passes its working scenarios, as it does for H2-S1. The negative result is therefore economic evidence against this frozen funding-only rule over this window, not a broker or execution conclusion.

The run is generated by:

```bash
uv run python -m moex_spread_lab.cli carry-strategy \
  --hypothesis h3-funding-only \
  --carry-study data/analytics/cnyrubf-crz6-carry-study.json \
  --benchmark data/benchmark/lqdt-lineage.json \
  --contracts data/w1/current-intake.json \
  --cost-scenario vtb_online_prime_current \
  --initial-capital 30000 \
  --output data/analytics/cnyrubf-crz6-funding-only-vtb.json
```

This is an exploratory comparison against LQDT, not a promotion gate. It must not be merged with H1 or H2-S1 accounting.

## Interpretation rule

H3-F1 tests the economic question "does received funding alone justify carrying this spread?" A result that is weaker than H2-S1 does not reject the pair; a positive result would still require a new frozen confirmation run, the same delay/cost/risk gates and separate evidence for fixing and execution events.
