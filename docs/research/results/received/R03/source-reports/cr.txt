Для запуска Python 3.13 и управления пакетами на macOS действительно часто используют явное указание версии интерпретатора. В частности, чтобы создать виртуальное окружение с нужной версией Python, можно выполнить команду вида: 
```bash
python3.13 -m venv venv
``` 
Это гарантирует, что окружение будет создано именно под Python 3.13. После этого активируйте окружение командой `source venv/bin/activate`. Тогда последующие команды `python` и `pip` будут соответствовать этой версии (внутри окружения они по умолчанию ссылаются на Python 3.13).  

При установке пакетов полезно использовать именно тот `pip`, который привязан к выбранному интерпретатору. Чтобы не было путаницы между системными или другими версиями Python, рекомендуется запускать его так: 
```bash
python3.13 -m pip install <имя_пакета>
``` 
или уже из активированного окружения: 
```bash
pip install <имя_пакета>
``` 
Таким образом гарантируется, что пакеты будут устанавливаться в контексте текущего виртуального окружения под Python 3.13. После создания окружения обычно дополнительно выполняют обновление `pip`: 
```bash
python3.13 -m pip install --upgrade pip
``` 
(Либо внутри venv просто `pip install --upgrade pip`.)  

Если на macOS установлено сразу несколько версий Python (например, системная 3.x и отдельно Python 3.13), такая явная версия нужна, чтобы не было конфликтов. Вместо постоянной ручной прописки `python3.13` можно также настроить менеджеры версий (например, [pyenv](https://github.com/pyenv/pyenv)), которые позволяют переключаться между разными интерпретаторами проще. Однако даже с ними в скриптах или инструкциях часто пишут `python3.13` и `python3.13 -m pip` для однозначности.  

**Коротко:** на macOS при использовании Python 3.13 создавайте виртуальное окружение командой `python3.13 -m venv venv`. После его активации или при установке пакетов всегда обращайтесь к `pip` через этот же интерпретатор: либо явно `python3.13 -m pip`, либо просто `pip` внутри активированного venv. Такой подход гарантирует, что вы устанавливаете библиотеки именно для нужной версии Python.
