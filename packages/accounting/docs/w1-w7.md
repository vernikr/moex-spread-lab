# W1–W7 — Offline research waves

Date: 2026-11-03

## Delivered

The offline pipeline in `src/moex_spread_lab/research.py` implements the remaining Stage-9 wave contracts over one explicitly synthetic fixture:

- **W1:** paginated catalog intake, aliases, stable contract identities and separate price roles;
- **W2:** primary-source corporate-action provenance, availability vintages, conflicts and derived-only price-gap diagnostics;
- **W3:** contract units, spread direction, quality status and non-zero cost components;
- **W4:** delayed native-spread and two-leg execution, stale quote rejection and visible partial/unbalanced execution;
- **W5:** append-only portfolio projection with matched LQDT path, `X`, `H`, `D`, costs and lifetime top-up usage;
- **W6:** no-trade control, fixed mean-reversion baseline, rejected carry trial, integer exposure ladder and stress gate;
- **W7:** chronological train/test split, delay/cost sensitivity, sign-flip null and explicit inconclusive result state.

The fixture is `fixtures/research/offline.json`. It is synthetic test data, not MOEX data, LQDT evidence or a profitability result. The module contract is `config/modules/w1-w7.json`; the run manifest pins both it and the fixture.

## Run

```bash
uv run python -m moex_spread_lab.cli research-pipeline \
  --manifest config/run-manifest.json \
  --fixture fixtures/research/offline.json \
  --output /tmp/w1-w7-pipeline.json
```

The command is network-disabled and deterministic. Write ad hoc output under `/tmp/`; canonical dated execution evidence is recorded in [GitHub Issue #32](https://github.com/vernikr/moex-spread-lab/issues/32), not committed under `reports/`.
