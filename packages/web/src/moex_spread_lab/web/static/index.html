0 — новый при каждом запуске

От него считаются все случайные величины проекта: подбор параметров Optuna. Ненулевое значение делает каждый запуск воспроизводимым — тот же сид даёт тот же результат. При 0 каждый запуск берёт новый сид, и повторный запуск может дать другой результат.
