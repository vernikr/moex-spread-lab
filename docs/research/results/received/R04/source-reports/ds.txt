# R04 — Бесплатные рыночные данные и историческая полнота по фьючерсам MOEX

**Дата исследования:** 2026-10-07  
**Языки поиска:** русский (основной), английский (дополнительный)  
**Статус:** независимый публичный сбор доказательств; измерения в рамках данного исследования не выполнялись

---

## 1. Краткие выводы

1. **Самый мелкий практически полезный бесплатный таймфрейм для истории фьючерсов MOEX — 1 минута.** Минутные свечи (OHLCV) доступны без авторизации через ISS как для действующих, так и для истёкших контрактов. Для текущего торгового дня данные приходят с задержкой около 15 минут; исторические свечи за прошлые периоды отдаются без дополнительной задержки, определяемой подпиской. Аудит подтвердил: запрос минутных свечей по истёкшему контракту `SiZ5` за 2025-11-01 вернул непустой массив данных (426 строк).

2. **Реальное время, стакан и исторические сделки бесплатно недоступны.** Официальный ISS прямо указывает: «Orderbooks and historical data are only available to the paid subscribers». Запрос `orderbook` для `SiZ5` вернул сообщение «Информация доступна только подписчикам». Исторические сделки (`trades`) за прошлые даты в бесплатном режиме также не отдаются (аудит: пустой массив `data`).

3. **Бесплатный тариф ALGOPACK «Стартовый / Starter»** даёт доступ к 15-минутным задержанным свечам и сделкам, но без онлайн-стакана. Онлайн-стакан и данные в реальном времени входят в платный тариф `Promo`.

4. **Брокерские API — жизнеспособная бесплатная альтернатива, но с условиями.** `T-Invest API` (Т-Банк) предоставляет бесплатный доступ к рыночным и историческим данным, но требует открытия брокерского счёта. `БКС Trade API` даёт WebSocket-потоки (свечи, стакан, сделки) в реальном времени, но также требует авторизации и, по-видимому, наличия счёта. У ВТБ публичного API нет: в поддержке пользователю отказали.

5. **Без платных или самостоятельно собранных котировок невозможны:** анализ микроструктуры (стакан, поток заявок), корректная оценка проскальзывания и исполнения, воспроизведение точных исторических bid/ask, а также любые высокочастотные стратегии. Для среднесрочных спредовых стратегий минутных OHLCV может быть достаточно для генерации сигналов, но не для реалистичного бэктеста исполнения.

6. **Юридическое ограничение:** бесплатные данные ISS доступны **только для ознакомления**. Любое иное использование (извлечение прибыли, распространение, создание производных продуктов) требует договора с ПАО Московская Биржа. Это ключевое ограничение, которое необходимо учитывать при проектировании исследовательского пайплайна.

## 3. Аудит публичных данных (только чтение)

Аудит выполнен 2026-10-07 без авторизации, без массовых выгрузок и без платных подписок. Использованы только HTTP GET-запросы к публичным endpoint’ам ISS.

### 3.1. Минутные свечи по истёкшему контракту `SiZ5`

**Запрос:**
```
https://iss.moex.com/iss/engines/futures/markets/forts/securities/SiZ5/candles.json?interval=1&from=2025-11-01&till=2025-11-02
```

**Результат:** HTTP 200. Массив `data` содержит 426 строк минутных свечей. Пример первой записи:
```json
[81749, 81749, 81749, 81749, 0, 12, "2025-11-01 08:59:00", "2025-11-01 08:59:59"]
```
Поля: `open`, `close`, `high`, `low`, `value`, `volume`, `begin`, `end`. Данные по истёкшему контракту доступны без авторизации.

### 3.2. Сделки по истёкшему контракту `SiZ5`

**Запрос:**
```
https://iss.moex.com/iss/engines/futures/markets/forts/securities/SiZ5/trades.json?from=2025-11-01&till=2025-11-01
```

**Результат:** HTTP 200. Массив `data` пуст (`"data": []`). Исторические сделки за прошлую дату в бесплатном режиме недоступны.

### 3.3. Стакан по контракту `SiZ5`

**Запрос:**
```
https://iss.moex.com/iss/engines/futures/markets/forts/securities/SiZ5/orderbook.json
```

**Результат:** HTTP 200, но содержимое — сообщение: «Информация доступна только подписчикам. The information is available only to subscribers».

### 3.4. Свечи по действующему контракту `SiM6` за праздничный день

**Запрос:**
```
https://iss.moex.com/iss/engines/futures/markets/forts/securities/SiM6/candles.json?interval=1&from=2026-01-01&till=2026-01-02
```

**Результат:** HTTP 200, пустой массив `data`. Это ожидаемо: 1 января — нерабочий день. Отсутствие данных не означает платность; это отсутствие торгов.

### 3.5. Выводы аудита

- Минутные OHLCV-свечи по фьючерсам (включая истёкшие контракты) **доступны бесплатно и без авторизации** через ISS.
- Исторические сделки и стакан **бесплатно недоступны**; требуется платная подписка.
- Для текущего дня бесплатные свечи приходят с задержкой ~15 минут (подтверждено документацией и обсуждениями: «Бесплатные данные передаются с задержкой 15 минут»).

## 4. Глубина истории и границы доступности

### 4.1. Заявленная и фактическая глубина

- Официальная документация не называет конкретную дату начала истории для фьючерсов, но указывает, что «historical data» доступны по подписке. При этом **свечи (candles)** в бесплатном режиме отдаются за прошлые периоды — аудит подтвердил данные за ноябрь 2025 г.
- Сторонние проекты сообщают, что котировки доступны **с 2012 года** для широкого круга инструментов MOEX. Для акций часовые свечи доступны с ноября 2011 г., для некоторых валют — с апреля 2013 г.. Прямых подтверждений по фьючерсам за 2012–2015 гг. в рамках аудита не получено; этот вопрос остаётся **условным**.
- `ALGOPACK` предоставляет исторические данные `SuperCandles` и `FUTOI` **с 2020 года**. Это означает, что для более ранних периодов бесплатные аналитические метрики (открытый интерес в разрезе физ/юр лиц и т.п.) недоступны.

### 4.2. Пагинация и ограничения запросов

- ISS поддерживает пагинацию через параметр `start`; ответы содержат поле `data` с записями, и для получения следующей порции необходимо увеличивать `start` на количество возвращённых строк.
- В документации ALGOPACK указано ограничение `limit <= 1000` записей на один запрос. Для ISS явных публичных ограничений на количество записей в одном ответе (кроме практических лимитов) не найдено, но при массовой выгрузке требуется пагинация.

### 4.3. Часовые пояса и границы торгового дня

- Данные ISS отдаются в московском времени (GMT+3). Границы торгового дня для срочного рынка определяются расписанием, доступным через `/iss/calendars/futures/session`. Пропуски сессий (выходные, праздники) отражаются как отсутствие записей, а не как нулевые цены.

## 5. Что можно и нельзя доказать на бесплатных данных

### 5.1. Что можно

- **Построение и проверка среднесрочных спредовых стратегий** на минутных или дневных свечах: генерация сигналов, расчёт доходности, оценка корреляций между контрактами.
- **Анализ исторической волатильности** на основе OHLCV.
- **Изучение сезонности и календарных эффектов** (экспирации, клиринговые дни).
- **Проверка гипотез о направлении спреда** без учёта микроструктуры исполнения.

### 5.2. Что нельзя

- **Реалистичный бэктест исполнения:** без исторических bid/ask и стакана невозможно оценить проскальзывание, частичное исполнение и реальные издержки. Свечи содержат только агрегированные цены сделок, а не котировки.
- **Анализ ликвидности на уровне заявок:** глубина рынка, спреды, дисбаланс заявок — только в платных или самостоятельно собранных данных.
- **Высокочастотные и арбитражные стратегии:** требуют real-time стакана и потока сделок.
- **Точное восстановление цен закрытия с учётом клиринга:** расчётные цены доступны, но их сопоставление с исполнением требует понимания методологии (см. ниже).

## 6. Кандидатный основной таймфрейм и альтернативы

- **Кандидат по умолчанию:** **1 минута**. Это самый мелкий бесплатный таймфрейм, доступный через ISS для истории и мониторинга (с задержкой 15 минут для текущего дня). Для среднесрочных спредовых стратегий минутных данных достаточно для генерации сигналов и первичной фильтрации.
- **Альтернативы:**
  - **5 минут** — компромисс между детализацией и объёмом данных; доступно через ALGOPACK (SuperCandles, обновление 5 мин).
  - **10 минут / 60 минут** — для снижения шума и объёма; доступно через ISS.
  - **Дневные свечи** — для грубой оценки исторической динамики и построения долгосрочных спредов.
- **Условия пригодности:** минутный таймфрейм пригоден для исследовательского бэктеста, но **не для исполнимого** без данных о bid/ask. Если стратегия требует оценки проскальзывания, необходимо либо переходить на платные данные, либо самостоятельно собирать стакан и сделки в реальном времени (что ограничено по ресурсам: VPS 1 vCPU / 1 ГБ RAM, бюджет 250–350 МБ).

## 7. Эскиз point-in-time данных и план будущего сбора

### 7.1. Что нужно фиксировать

- **Спецификации контрактов:** `secid`, дата экспирации, множитель, шаг цены, базовый актив. Доступны через ISS (справочники).
- **Версии данных:** фиксировать `updatetime` из ISS, чтобы понимать, на какой момент времени были получены данные.
- **Приём данных:** временная метка загрузки, источник (ISS, ALGOPACK, брокерский API), параметры запроса.
- **Границы дня:** использовать календарь торгов срочного рынка (`/iss/calendars/futures/session`).

### 7.2. Оценка объёма и хранения

- **Одна минутная свеча** (OHLCV + timestamp) занимает ~50–60 байт в компактном формате (CSV/Parquet). Для одного контракта за год (~250 торговых дней × ~600 минут) — около 150 000 записей, ~8–10 МБ. Для вселенной из 50 пар — ~400–500 МБ в год. Это укладывается в 20 ГБ диска VPS, но требует регулярной архивации.
- **Самостоятельный сбор стакана** в реальном времени (если появится платный доступ или брокерский API) потребует значительно больше ресурсов: при 10 обновлениях в секунду и глубине 20 уровней — десятки ГБ в месяц. Это выходит за рамки текущего бюджета фоновых задач.

### 7.3. План при отсутствии исторических bid/ask и ГО

1. **Использовать минутные OHLCV** для исследовательского бэктеста, явно помечая его как «неисполнимый» (research backtest).
2. **Для оценки исполнения** — либо переходить на платные данные MOEX (End-of-Day + Delayed streaming), либо использовать брокерский API (БКС, T-Invest) для сбора собственного архива стакана и сделок в реальном времени.
3. **ГО и ставки риска:** доступны через ISS (справочники) и обновляются; для point-in-time необходимо фиксировать версии. Исторические изменения ГО можно восстановить только при наличии архива или платных данных.

## 8. Противоречия и неизвестное

- **Различие между «historical data» и «candles».** В руководстве разработчика ISS сказано: «Orderbooks and historical data are only available to the paid subscribers». Однако аудит показал, что минутные свечи за прошлые периоды доступны бесплатно. Это противоречие указывает на то, что под «historical data» в документе, вероятно, понимаются **исторические сделки** (tick data) или **полные архивы**, а не агрегированные свечи. Для точного понимания требуется уточнение у MOEX.
- **Глубина истории по фьючерсам до 2020 г.** не подтверждена прямыми запросами. Сторонние источники упоминают 2012 г., но официального подтверждения в рамках аудита не получено.
- **Условия использования брокерских API** (T-Invest, БКС) в части хранения и распространения данных не проверялись детально. Требуется ознакомление с пользовательскими соглашениями.

## 9. Условия опровержения и возможные изменения проекта

- Если MOEX изменит условия доступа к ISS (например, закроет бесплатные свечи), вывод о минутном таймфрейме как основном бесплатном источнике потеряет силу.
- Если пользователь получит статус квалифицированного инвестора у брокера с API (например, БКС), объём доступных бесплатных данных может расшириться за счёт брокерского потока.
- Если бюджет позволит платную подписку MOEX (от 500 USD/мес за End-of-Day data), можно будет получить исторические сделки и стакан, что откроет возможность исполнимого бэктеста.
- Появление новых бесплатных источников (например, расширение ALGOPACK Starter) может изменить ландшафт.

## 11. Итоговый ответ на вопрос

**Самые мелкие практически полезные бесплатные данные по фьючерсам MOEX — минутные свечи (OHLCV) через ISS.** Они доступны без авторизации для истории (включая истёкшие контракты) и с задержкой ~15 минут для текущего дня. Стакан, исторические сделки и реальное время бесплатно недоступны; их можно получить только по платной подписке MOEX, через платный тариф ALGOPACK Promo или через брокерские API при наличии счёта (T-Invest, БКС).

**Без платных или самостоятельно собранных котировок невозможно:** реалистично оценить проскальзывание и исполнение, анализировать микроструктуру рынка, проводить высокочастотные и арбитражные стратегии, а также строить исполнимый (execution-aware) бэктест. Для среднесрочных спредовых стратегий минутных свечей достаточно для исследовательского бэктеста, но не для торговых решений, чувствительных к качеству исполнения.
